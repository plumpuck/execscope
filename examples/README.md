# examples/

Small scripts written while learning NautilusTrader (`peek_bar.py`: how a CSV row becomes a `Bar`).
Run it inside the official example folder `examples/backtest/example_01_load_bars_from_custom_csv`
(develop_v1 branch of https://github.com/nautechsystems/nautilus_trader), next to its CSV.

**Source and license:** NautilusTrader is LGPL-3.0. `peek_bar.py` follows that example's structure,
so treat it as derived from it. The official example files themselves are not copied here.
ExecScope's own code lives in `src/execscope/` and does not copy Nautilus source.
